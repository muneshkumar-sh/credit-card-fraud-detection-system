# Credit Card Fraud Detection Using Machine Learning

## Overview

This project is a Machine Learning-based Credit Card Fraud Detection System developed using Python, Scikit-learn, XGBoost, and Streamlit.

The goal of this project is to identify fraudulent and legitimate credit card transactions using AI and Machine Learning techniques.

---

## Problem Statement

Credit card fraud is increasing rapidly worldwide, and traditional rule-based systems often fail to detect modern fraud patterns efficiently. This project aims to build an intelligent fraud detection system capable of identifying suspicious transactions accurately.

---

## Dataset

* Dataset: Kaggle Credit Card Fraud Detection Dataset
* Total Transactions: 284,807
* Fraud Cases: 0.17%

---

## Technologies Used

* Python
* Pandas

* XGBoost

---

## Machine Learning Models

* Logistic Regression
* Random Forest
* XGBoost

### Best Model

Random Forest achieved the best performance:

* Accuracy: 99.94%
* Precision: 92%
* Recall: 73%
* F1 Score: 81%
